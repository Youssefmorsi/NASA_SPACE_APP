# Two-minute demonstration

1. Explore the textured Moon. Select LROC observation center and open its actual product record; the red polygon is the image footprint, not a hazard map.
2. Select South polar reference. Open Plan this location.
3. Explain UTC dates, reference-sphere height, Sun/Earth thresholds and user requirements. Calculate the default 13–20 November 2026 interval (genuine cached Horizons response).
4. Inspect elevation charts, interpolated interval tracks and requirement checks. Open provenance and original response.
5. Load sourced examples, choose two, compare matching metrics and read deterministic trade-offs. Switch UTC/elapsed axes explicitly.
6. Export CSV. End with Sources: no terrain obstruction, hazards, link budget or landing safety assessment.
